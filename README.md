Developed a 3D rail-shooter game using Python and PyOpenGL, featuring real-time rendering, depth-based world scrolling, and both first-person and third-person camera modes. The game incorporates modular gameplay systems such as enemy AI, collision detection, fuel and health management, scoring, HUD elements, and cheat/debug functionality. Implemented frame-rate independent updates to ensure smooth and consistent gameplay, while maintaining a reusable, modular, and extensible code structure for future improvements.
