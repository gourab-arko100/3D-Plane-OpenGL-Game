## 3D Plane Game (Python, OpenGL)

The **3D Plane Game** is a rail-shooter style game developed using **Python and PyOpenGL**, featuring real-time 3D rendering, depth-based world scrolling, and both first-person and third-person camera modes. The game includes modular gameplay systems such as enemy AI, collision detection, fuel and health management, scoring, HUD elements, and cheat/debug functionality. Frame-rate independent updates are implemented to ensure smooth and consistent gameplay, with a reusable and extensible code structure for future improvements.
